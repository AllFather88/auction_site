# Разработка сайта онлайн-аукциона

Веб-приложение для проведения онлайн-аукционов с возможностью регистрации пользователей, создания лотов, совершения ставок и отслеживания торгов в реальном времени. Проект выполняется в рамках курсовго проекта.

## Стек технологий

| Слой | Технологии |
|------|-----------|
| **Backend** | Java 17+, Spring Boot 3.x, Spring Web, Spring Data MongoDB, Spring Data Redis |
| **Frontend** | JavaScript (Vanilla JS / модульный подход), HTML5, CSS3 |
| **База данных** | MongoDB (основное хранилище: пользователи, лоты, ставки) |
| **Кэш / сессии** | Redis (кэширование активных лотов, временное хранение данных сессий) |
| **Сборка** | Maven |

> **Почему MongoDB + Redis?** MongoDB используется как основная документная БД для гибкого хранения сущностей аукциона (лоты с разной структурой, история ставок). Redis применяется для кэширования часто запрашиваемых данных (например, текущей цены активных лотов) и снижения нагрузки на основную БД .

## Функциональность (MVP)

- **Пользователи**: регистрация, вход, личный кабинет.
- **Лоты**: создание лота (название, описание, стартовая цена, шаг ставки, время окончания), просмотр списка активных лотов, карточка лота.
- **Ставки**: совершение ставки (проверка: ставка выше текущей + шаг, лот активен).
- **Таймер**: отображение времени до окончания торгов.
- **История**: список ставок по каждому лоту.
